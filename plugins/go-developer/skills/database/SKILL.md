# Go Database Access

## Choosing the Right Tool

| Tool | Best for | Trade-off |
|------|----------|-----------|
| **GORM** | Rapid development, CRUD-heavy apps | Magic behaviour, harder to debug generated SQL |
| **sqlc** | Performance-critical, SQL-first teams | Requires SQL schema + queries upfront; code generation step |
| **sqlx** | Full SQL control with less boilerplate than `database/sql` | Still manual query writing; no code generation |
| **pgx** | Maximum PostgreSQL performance and feature access | PostgreSQL-only; lower-level API |

---

## GORM — Feature-Rich ORM

Good for rapid development. Auto-migrates schemas, handles associations, and generates SQL from struct methods.

```bash
go get gorm.io/gorm
go get gorm.io/driver/postgres
```

### Setup

```go
import (
    "gorm.io/driver/postgres"
    "gorm.io/gorm"
    "gorm.io/gorm/logger"
)

func NewDB(dsn string) (*gorm.DB, error) {
    db, err := gorm.Open(postgres.Open(dsn), &gorm.Config{
        Logger: logger.Default.LogMode(logger.Warn),  // log slow queries only
    })
    if err != nil {
        return nil, fmt.Errorf("open db: %w", err)
    }

    sqlDB, _ := db.DB()
    sqlDB.SetMaxOpenConns(25)
    sqlDB.SetMaxIdleConns(10)
    sqlDB.SetConnMaxLifetime(5 * time.Minute)

    return db, nil
}
```

### Model definition

```go
type User struct {
    gorm.Model                         // adds ID, CreatedAt, UpdatedAt, DeletedAt
    Name  string `gorm:"not null"`
    Email string `gorm:"uniqueIndex;not null"`
}
```

### CRUD

```go
// Create
user := &User{Name: "Alice", Email: "alice@example.com"}
if err := db.Create(user).Error; err != nil {
    return fmt.Errorf("create user: %w", err)
}

// Read
var user User
if err := db.First(&user, "id = ?", id).Error; err != nil {
    if errors.Is(err, gorm.ErrRecordNotFound) {
        return nil, ErrNotFound
    }
    return nil, err
}

// Update — only changed fields
db.Model(&user).Updates(User{Name: "Bob"})

// Delete (soft-delete with gorm.Model)
db.Delete(&user)
```

### Preloading associations

```go
type Order struct {
    gorm.Model
    UserID uint
    User   User
    Items  []OrderItem `gorm:"foreignKey:OrderID"`
}

// Load Order with User and Items in one call
var order Order
db.Preload("User").Preload("Items").First(&order, id)
```

> **Avoid `db.AutoMigrate` in production.** Use it only in development. Run schema migrations through a dedicated tool like `golang-migrate` in production.

## sqlc — Type-Safe SQL Code Generation

sqlc reads your SQL schema and queries, and generates fully typed Go code. No reflection, no runtime SQL building — preferred when performance and correctness matter.

```bash
go install github.com/sqlc-dev/sqlc/cmd/sqlc@latest
go get github.com/sqlc-dev/sqlc
```

### Configuration

```yaml
# sqlc.yaml
version: "2"
sql:
  - engine: "postgresql"
    queries: "./internal/repository/queries"
    schema:  "./migrations"
    gen:
      go:
        package:      "repository"
        out:          "./internal/repository"
        emit_json_tags: true
        emit_interface: true
```

### Write SQL, get Go

```sql
-- internal/repository/queries/users.sql

-- name: GetUser :one
SELECT id, name, email, created_at
FROM users
WHERE id = $1;

-- name: ListUsers :many
SELECT id, name, email, created_at
FROM users
ORDER BY created_at DESC
LIMIT $1 OFFSET $2;

-- name: CreateUser :one
INSERT INTO users (name, email)
VALUES ($1, $2)
RETURNING *;

-- name: DeleteUser :exec
DELETE FROM users WHERE id = $1;
```

```bash
sqlc generate    # generates internal/repository/*.go
```

### Use the generated code

```go
// internal/repository/user_repo.go
type userRepository struct {
    q *repository.Queries   // generated by sqlc
}

func (r *userRepository) FindByID(ctx context.Context, id uuid.UUID) (*domain.User, error) {
    row, err := r.q.GetUser(ctx, id)
    if errors.Is(err, pgx.ErrNoRows) {
        return nil, domain.ErrNotFound
    }
    if err != nil {
        return nil, fmt.Errorf("find user: %w", err)
    }
    return mapUserToDomain(row), nil
}
```

### Transactions with sqlc

```go
func (r *userRepository) TransferCredits(ctx context.Context, fromID, toID uuid.UUID, amount int32) error {
    return withTx(ctx, r.db, func(tx pgx.Tx) error {
        q := r.q.WithTx(tx)   // sqlc supports WithTx natively

        if err := q.DebitAccount(ctx, repository.DebitAccountParams{
            UserID: fromID, Amount: amount,
        }); err != nil {
            return fmt.Errorf("debit: %w", err)
        }

        if err := q.CreditAccount(ctx, repository.CreditAccountParams{
            UserID: toID, Amount: amount,
        }); err != nil {
            return fmt.Errorf("credit: %w", err)
        }

        return nil
    })
}
```

## sqlx — Thin Wrapper over `database/sql`

Adds struct scanning and named queries while keeping you in full control of SQL. No code generation required.

```bash
go get github.com/jmoiron/sqlx
```

### Setup

```go
func NewDB(dsn string) (*sqlx.DB, error) {
    db, err := sqlx.Connect("postgres", dsn)   // Open + Ping
    if err != nil {
        return nil, fmt.Errorf("connect db: %w", err)
    }

    db.SetMaxOpenConns(25)
    db.SetMaxIdleConns(10)
    db.SetConnMaxLifetime(5 * time.Minute)
    db.SetConnMaxIdleTime(2 * time.Minute)

    return db, nil
}
```

### Struct scanning

```go
type User struct {
    ID        uuid.UUID `db:"id"`
    Name      string    `db:"name"`
    Email     string    `db:"email"`
    CreatedAt time.Time `db:"created_at"`
}

// Single row
func (r *userRepository) FindByID(ctx context.Context, id uuid.UUID) (*User, error) {
    var user User
    err := r.db.GetContext(ctx, &user,
        `SELECT id, name, email, created_at FROM users WHERE id = $1`, id)
    if errors.Is(err, sql.ErrNoRows) {
        return nil, ErrNotFound
    }
    if err != nil {
        return nil, fmt.Errorf("find user: %w", err)
    }
    return &user, nil
}

// Multiple rows
func (r *userRepository) ListUsers(ctx context.Context) ([]*User, error) {
    var users []*User
    err := r.db.SelectContext(ctx, &users,
        `SELECT id, name, email, created_at FROM users ORDER BY created_at DESC`)
    if err != nil {
        return nil, fmt.Errorf("list users: %w", err)
    }
    return users, nil
}
```

### Named queries (struct as params)

```go
func (r *userRepository) Save(ctx context.Context, u *User) error {
    _, err := r.db.NamedExecContext(ctx, `
        INSERT INTO users (id, name, email, created_at)
        VALUES (:id, :name, :email, :created_at)
        ON CONFLICT (id) DO UPDATE SET
            name  = EXCLUDED.name,
            email = EXCLUDED.email
    `, u)
    if err != nil {
        return fmt.Errorf("save user: %w", err)
    }
    return nil
}
```

## pgx — Best PostgreSQL Driver

pgx provides direct access to PostgreSQL features: COPY protocol, LISTEN/NOTIFY, pipeline mode, and binary encoding. Faster than `lib/pq` for high-throughput services.

```bash
go get github.com/jackc/pgx/v5
```

### Setup with connection pool

```go
import "github.com/jackc/pgx/v5/pgxpool"

func NewPool(ctx context.Context, dsn string) (*pgxpool.Pool, error) {
    cfg, err := pgxpool.ParseConfig(dsn)
    if err != nil {
        return nil, fmt.Errorf("parse pgx config: %w", err)
    }

    cfg.MaxConns = 25
    cfg.MinConns = 5
    cfg.MaxConnLifetime = 5 * time.Minute
    cfg.MaxConnIdleTime = 2 * time.Minute

    pool, err := pgxpool.NewWithConfig(ctx, cfg)
    if err != nil {
        return nil, fmt.Errorf("create pool: %w", err)
    }

    if err := pool.Ping(ctx); err != nil {
        return nil, fmt.Errorf("ping db: %w", err)
    }

    return pool, nil
}
```

### Querying

```go
func (r *userRepository) FindByID(ctx context.Context, id uuid.UUID) (*User, error) {
    row := r.pool.QueryRow(ctx,
        `SELECT id, name, email, created_at FROM users WHERE id = $1`, id)

    var user User
    err := row.Scan(&user.ID, &user.Name, &user.Email, &user.CreatedAt)
    if errors.Is(err, pgx.ErrNoRows) {
        return nil, ErrNotFound
    }
    if err != nil {
        return nil, fmt.Errorf("find user: %w", err)
    }
    return &user, nil
}
```

### LISTEN / NOTIFY

```go
conn, _ := pgx.Connect(ctx, dsn)
defer conn.Close(ctx)

if _, err := conn.Exec(ctx, "LISTEN orders"); err != nil {
    return err
}

for {
    notification, err := conn.WaitForNotification(ctx)
    if err != nil {
        return err
    }
    slog.Info("notification", "channel", notification.Channel, "payload", notification.Payload)
}
```

### pgx is also the backend for sqlc

sqlc generates code that targets pgx by default when `engine: postgresql` is set — you get the best of both: type-safe generated queries and the fastest PostgreSQL driver.

## Repository Pattern

Define the interface in the domain layer, implement with whichever tool you choose.

```go
// internal/domain/user.go
type UserRepository interface {
    FindByID(ctx context.Context, id uuid.UUID) (*User, error)
    List(ctx context.Context, params ListParams) ([]*User, error)
    Save(ctx context.Context, u *User) error
    Delete(ctx context.Context, id uuid.UUID) error
}
```

The service layer depends only on this interface — it never imports GORM, sqlc, sqlx, or pgx directly.

## Transactions — Shared Pattern

```go
// Works with *sql.DB, *sqlx.DB, or *pgxpool.Pool (adapt the type)
func withTx(ctx context.Context, db *sqlx.DB, fn func(*sqlx.Tx) error) error {
    tx, err := db.BeginTxx(ctx, nil)
    if err != nil {
        return fmt.Errorf("begin tx: %w", err)
    }

    defer func() {
        if p := recover(); p != nil {
            _ = tx.Rollback()
            panic(p)
        }
    }()

    if err := fn(tx); err != nil {
        _ = tx.Rollback()
        return err
    }

    return tx.Commit()
}
```

## Migrations with `golang-migrate`

Works with all four drivers above.

```bash
go get -u github.com/golang-migrate/migrate/v4
```

```
migrations/
├── 000001_create_users.up.sql
├── 000001_create_users.down.sql
└── 000002_add_email_index.up.sql
    000002_add_email_index.down.sql
```

```sql
-- migrations/000001_create_users.up.sql
CREATE TABLE users (
    id         UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    name       TEXT NOT NULL,
    email      TEXT NOT NULL UNIQUE,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
```

```go
func runMigrations(dsn string) error {
    m, err := migrate.New("file://migrations", dsn)
    if err != nil {
        return fmt.Errorf("create migrator: %w", err)
    }
    defer m.Close()

    if err := m.Up(); err != nil && !errors.Is(err, migrate.ErrNoChange) {
        return fmt.Errorf("run migrations: %w", err)
    }

    return nil
}
```

## Parameterized Queries — Never Concatenate SQL

```go
// Bad — SQL injection
query := fmt.Sprintf("SELECT * FROM users WHERE name = '%s'", name)

// Good — parameterized ($1 for pgx/sqlx, ? for MySQL/SQLite)
row := db.QueryRowContext(ctx, `SELECT id, name FROM users WHERE name = $1`, name)
```

## Audit Checklist

1. **SQL built by string concatenation** — direct user input in queries enables SQL injection; always use parameterized queries with `$1` / `?` / named parameters
2. **`db.AutoMigrate` used in production (GORM)** — auto-migration in production can silently alter or drop columns; use `golang-migrate` or Atlas with explicit, versioned migration files
3. **No connection pool limits** — default `MaxOpenConns` is unlimited (sqlx/database/sql) or very high (pgx); cap it to avoid exhausting the database under load
4. **`rows.Close()` not deferred (sqlx/database/sql)** — unclosed rows hold a connection; always `defer rows.Close()` immediately after error check
5. **`rows.Err()` not checked after iteration (sqlx/database/sql)** — errors during scanning are not surfaced by `rows.Next()`; check `rows.Err()` after the loop
6. **Transactions not rolled back on error** — an open transaction holds locks; use a `withTx` wrapper that calls `Rollback` unconditionally on error
7. **`sql.ErrNoRows` / `pgx.ErrNoRows` / `gorm.ErrRecordNotFound` leaking past the repository** — translate driver-specific not-found errors to a domain sentinel (`ErrNotFound`) at the repository boundary
8. **sqlc queries out of sync with schema** — running `sqlc generate` only locally means the generated code drifts; add `sqlc generate && git diff --exit-code` to CI
9. **GORM N+1 queries on associations** — accessing a relation in a loop without `Preload` fires one query per row; always `Preload` known associations up front
10. **Migrations run inside the application on startup** — running `migrate.Up()` in `main()` couples deployment to migration and blocks startup on slow migrations; use a dedicated `migrate` binary or init container
